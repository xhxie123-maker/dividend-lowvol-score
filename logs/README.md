# 每日日志存档

每个交易日一份独立日志，文件名即**数据日期**（最新交易日收盘日），由 `dividend_lowvol_score.py` 自动生成，随 GitHub Actions 一起提交。

单份日志包含：

1. **评分总览** — 两只标的的收盘价、综合评分、评级、较前一日变化、数据覆盖率
2. **子项拆解** — 7 个维度各自的权重、得分、状态（优/良/中性/弱），以及缺失维度说明
3. **关键指标** — 净值、收益、超额、均线、波动、回撤、估值分位、折溢价、股息率、成交额
4. **解读** — 由指标规则生成的一段中文说明
5. **横向对比** — 两者评分排序、差值、逐维度对照与费率提示
6. **数据异常** — 交易日与运行日不一致、抓取失败等
7. **口径与免责** — 模型边界说明

命名与幂等：

- 同一数据日期重复运行会覆盖同一份日志（内容刷新），不会产生重复文件
- 非交易日不会生成新日志；若手动运行，日志会记录「最新交易日与运行日不一致」的提示
- 历史评分与历史快照分别留存于 `../data/daily_scores.csv` 与 `../data/history/`，日志属于人读版本

索引：仓库看板 `docs/index.html` 底部会列出最近 12 份日志的直达链接。
