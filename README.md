# 红利低波 ETF 每日监测评分

对两只红利低波 ETF 做统一口径的逐日量化打分，每个交易日自动更新，并保留**每日独立日志存档**。

- 在线看板：<https://xhxie123-maker.github.io/dividend-lowvol-score/>
- 全部历史评分：`data/daily_scores.csv`
- 每日日志：`logs/YYYY-MM-DD.md`
- 当日快照：`data/history/YYYY-MM-DD.json`

## 监测标的

| 简称 | 代码 | 基金全称 | 跟踪指数 | 管理费+托管费 |
| --- | --- | --- | --- | --- |
| 南方红利低波 | **515450** | 南方标普中国A股大盘红利低波50ETF | 标普中国A股大盘红利低波50指数 | 0.50% + 0.10% |
| 易方达红利低波 | **563020** | 易方达中证红利低波动ETF | 中证红利低波动指数（H30269） | 0.15% + 0.05% |

两只产品同属「高股息 + 低波动」风格，但跟踪不同指数、费率结构不同，适合用同一把尺子横向比较。

## 评分模型

综合分 = 7 个维度加权，各子项先归一化到 0–100，再按权重合成；某维度数据缺失时按剩余权重重新归一化，并在日志里标注覆盖率。

| 维度 | 权重 | 计算口径 | 方向 |
| --- | --- | --- | --- |
| 趋势 | 25% | 价格对 MA20、MA20 对 MA60、MA20 五日斜率、价格对 MA120 四项的均值 | 越强越高 |
| 动量 | 20% | 20/60 日绝对收益 + 相对沪深300 的 20/60 日超额，四项均值 | 越强越高 |
| 波动 | 20% | 20 日、60 日年化波动率、60 日下行波动率（按红利低波常态 8%–20% 标定） | 越低越高 |
| 回撤 | 15% | 距 250 日高点回撤（−12% 归零）、60 日最大回撤（−8% 归零） | 越浅越高 |
| 估值 | 10% | 价格在近 750 日区间的分位（反向）+ 近 12 个月股息率的历史分位（正向） | 越便宜越高 |
| 红利 | 5% | 近 12 个月每份现金分红合计 / 不复权收盘价，2%–5% 线性标定 | 越高越高 |
| 交易质量 | 5% | 20 日均成交额、当日成交额/60 日均值、近 20 日平均折溢价绝对值 | 越活跃、折溢价越小越高 |

评级带：≥80 强势 / 65–80 偏强 / 50–65 中性 / 35–50 偏弱 / <35 弱势，并附对应操作提示。

### 为什么这样设计

- **红利低波的痛点不在「买不买」，而在「贵不贵、稳不稳」**：波动与回撤合计 35% 权重，直接对应这只产品的持有体验。
- **估值不用指数 PE**：指数 PE 需要额外授权数据源且口径不统一，改用「价格分位 + 股息率分位」两个可复算的代理指标，两只标的可比。
- **折溢价用不复权价**：ETF 分红会让前复权价与单位净值错位，折溢价必须以同日未复权收盘价对单位净值计算，否则会出现 1% 级别的假折价。
- **动量对基准取超额**：红利风格常年跑赢或跑输宽基，绝对收益无法区分「风格 beta」和「个券 alpha」。

## 每日更新机制

GitHub Actions（`.github/workflows/daily.yml`）：

- 定时：每周一至周五 **UTC 00:20 / 北京时间 08:20** 自动运行
- 支持手动触发：Actions →「每日红利低波评分」→ Run workflow
- 运行后自动提交 `data/`、`logs/`、`docs/` 的变更，并由 GitHub Pages 发布 `docs/index.html`

单次运行约 6 次网络请求（3 组日线 + 2 只 ETF 的净值增量），净值历史落盘缓存于 `data/cache/nav_*.csv`，因此首次运行翻页较慢、之后每天只取最新一页。

### 产物

| 路径 | 内容 |
| --- | --- |
| `data/daily_scores.csv` | 逐日逐标的评分与全部原始指标（滚动积存，不覆盖历史） |
| `data/history/YYYY-MM-DD.json` | 当日完整快照：子分项、原始指标、数据覆盖率、缺失维度 |
| `logs/YYYY-MM-DD.md` | 当日独立日志：评分表、子项拆解、关键指标、横向对比、数据异常 |
| `docs/index.html` | 看板：评分卡片、30 日走势、维度对比、近 30 日明细、日志索引 |
| `data/run_history.jsonl` | 每次运行的审计记录（运行时间、数据日期、错误） |

## 本地运行

```bash
python dividend_lowvol_score.py          # 抓数 + 计算 + 生成全部产物
python dividend_lowvol_score.py --offline # 仅用本地缓存（调试用）
```

仅依赖 Python 标准库（3.9+），无需 pip 安装。脚本优先用 `urllib`，遇到网络受限环境会自动回退到系统 `curl`。

参数集中在 `config.json`：标的、权重、评级带、回看窗口，改完直接重跑即可。

## 口径说明与边界

- 评分为**相对强弱排序工具**，不是买卖信号，也不含任何仓位建议。
- 数据全部来自东方财富公开接口（日线前复权、单位净值、每份分红）与沪深300 指数；接口若变更或延迟，日志的「数据异常」段落会显式记录。
- 最新交易日与运行日不一致（周末、节假日、数据延迟）时仍照常生成，但会在日志中提示。
- 历史分位窗口受上市时间限制：563020 于 2023-12 上市，分位窗口实际不足 750 日时按实际长度计算。
